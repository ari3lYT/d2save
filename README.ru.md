# D2Save

[English](README.md) · **Русский**

D2Save — серверный Fabric-мод, который во время автосохранения выносит запись ванильных данных игроков и метаданных мира с тикового потока Minecraft.

Мод появился после профилирования многосекундных зависаний при автосохранении на накопителях с высокой задержкой `fsync`. Игрокам не нужно устанавливать его на клиент. Мод не меняет чанки, частоту автосохранения, игровой процесс, команды, права, рецепты или формат NBT на диске.

## Совместимость

- Minecraft `1.21.11`
- Fabric Loader `0.18.4+`
- Fabric API
- Java 21

## Как это работает

Внутри `MinecraftServer.runAutosave` D2Save сериализует данные игрока и метаданные мира в серверном потоке, создаёт независимую копию NBT и передаёт запись на диск одному ограниченному FIFO-обработчику.

Защитные барьеры завершают ожидающие операции записи перед:

- новой серией автосохранения;
- ручным сохранением и `/save-all flush`;
- загрузкой данных игрока и сохранением при выходе;
- чтением, изменением, резервным копированием и восстановлением метаданных мира;
- остановкой сервера.

Сохраняются ванильные gzip NBT, синхронная запись файлов, замена через временный файл и резервные копии `.dat_old`. Если фоновая запись ломается, ошибка попадает в журнал, а дальнейшие записи до перезапуска выполняются обычным синхронным способом. Ограниченная очередь создаёт обратное давление вместо бесконтрольного расхода памяти.

## Компромисс

Между созданием снимка и завершением его записи существует короткое окно. Аварийное завершение процесса или ОС в этот момент может потерять последнее ожидающее автосохранение. При штатной остановке и явном сохранении очередь сначала опустошается. D2Save уменьшает задержки, но не заменяет резервные копии.

## Сборка и тесты

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 ./gradlew test build
```

JUnit-тесты проверяют порядок FIFO, барьеры, обратное давление, обработку ошибок, остановку и сохранение статуса прерывания.

В репозитории также есть изолированный игровой тест Fabric-клиента:

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 \
LIBGL_ALWAYS_SOFTWARE=1 ALSOFT_DRIVERS=null \
xvfb-run -a -s '-screen 0 1280x720x24 -nolisten tcp' \
./gradlew runClientGameTest
```

Он проверяет независимые снимки, неблокирующее автосохранение, упорядоченные резервные копии, барьеры ручного сохранения, сохранность после остановки и повторного запуска, искусственный сбой диска и синхронный запасной режим.

Готовый JAR появляется в `build/libs/`.

## Установка

1. Создайте резервную копию мира.
2. Установите на сервер Fabric Loader и Fabric API.
3. Поместите JAR D2Save в `mods/`.
4. Обычным образом перезапустите сервер.

После удаления D2Save преобразование данных не требуется: сохранения остаются ванильными NBT.
